<task type="auto">
  <name>Task 1: Cross-panel consistency audit and fixes</name>
  <files>All panel files from Plans 02-06, packages/dashboard/src/main.css</files>
  <action>
Run a systematic audit across all converted panels:

**1. Padding consistency:**
Grep all panel root containers for padding classes: `p-4`, `p-5`, `p-6`, `px-*`, `py-*`.
Standardize: all panel root containers should use `p-6` (24px). If any use p-4 or p-5, update to p-6.

**2. Panel header pattern:**
Every panel should have a consistent header structure:
```tsx
<div className="flex items-center justify-between mb-4">
  <h1 className="text-base font-medium">Panel Title</h1>
  <div className="flex items-center gap-2">{/* controls */}</div>
</div>
```
Check: h1 sizing consistent (text-base font-medium), margin-bottom consistent (mb-4), flex justify-between for header layout.

**3. Border-radius audit:**
Grep all files for hardcoded border-radius values: `rounded-xl`, `rounded-2xl`, `rounded-lg`, `rounded-md`, `border-radius: 16px`, `border-radius: 12px`.
All containers should use `rounded-[var(--radius-panel)]` (14px) or inherit from glass-panel class.
All controls should use `rounded-[var(--radius-button)]` (10px) or inherit from glass-button/glass-input/glass-select.
Fix any outliers.

**4. Hardcoded color audit:**
Grep for hardcoded hex colors (`#[0-9a-f]{3,6}`), hardcoded rgb/rgba that should be tokens, Tailwind color classes that should be token references.
Acceptable: oklch values that match @theme tokens, rgba in glass utility classes.
Problematic: `text-gray-400`, `bg-gray-800`, `border-gray-700`, `#e8e8ed` inline (should be var(--color-text-primary)).
Fix: replace with token references or Tailwind token classes (text-text-primary, bg-bg-surface, etc.)

**5. Glass-on-glass audit:**
Search for any component that renders `.glass-panel` inside another `.glass-panel`. Common offenders:
- Database panel: inner browser/viewer components
- Settings panel: section containers
- Any "card inside a panel" pattern
Fix: inner elements should use `bg-bg-surface/10` or transparent, not glass-panel.

**6. Empty state consistency:**
All "no device selected", "no data", "loading" states should use glass-empty-state class.
Check: icon (if any) + message text centered, consistent sizing.

**7. Transition consistency:**
All interactive elements should have `transition: ... 0.15s ease` or inherit from glass utility.
Check: no jarring state changes, no missing hover transitions.

**8. main.css cleanup:**
If the audit reveals patterns that should be additional utilities, add them to main.css.
If any existing utilities need tweaking (padding, color values), update them.

Commit any fixes found during audit.
