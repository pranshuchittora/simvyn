## Primary Screen Contract

Screen: `packages/dashboard/src/panels/AppPanel.tsx`

Focal point:
- The `.glass-drop-zone` remains the primary visual anchor above the app list.
- While a file or bundle is dragged over the panel, the active drop-zone border/background becomes the visual priority.
- During upload, the spinner plus `Installing {packageName}...` status replaces the browse controls.

Layout:
- Keep the existing App Management header and Refresh button unchanged.
- Keep `InstallDropZone` directly above `AppList`.
- Inside the drop zone, stack instruction text above browse controls.
- Browse controls render on one row on desktop and may wrap to two rows on narrow widths.
- Do not add another surrounding card around the drop zone.

Controls:
- File browse input accepts `.ipa,.apk`.
- Bundle browse input is a separate hidden directory input configured with `webkitdirectory` imperatively.
- Drag/drop supports single-file `.ipa`/`.apk` and one root directory ending in `.app`.
- If both a file and directory are dropped, prefer the `.app` directory only when exactly one `.app` root is present; otherwise show `Only .ipa, .apk, and iOS simulator .app bundles are accepted`.

Accessibility:
- Buttons must have visible text labels, not icon-only controls.
- The hidden inputs must be triggered by buttons with clear labels.
- Status text must remain in the DOM under the browse controls or spinner so screen readers encounter the latest result after an action.
- Keyboard users must be able to tab to both browse actions.
