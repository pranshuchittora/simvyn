<objective>
Add backend support for safe iOS simulator `.app` bundle uploads.

Purpose: The iOS adapter already installs direct `.app` paths, but the app-management install route only accepts one uploaded file. This plan adds a server-side multipart protocol for `.app` directory bundles, reconstructs them in a temp directory with strict path validation, and preserves the existing `.ipa`/`.apk` upload behavior.

Output: `/api/modules/apps/install/:deviceId` accepts existing single-file uploads and new iOS simulator `.app` bundle uploads.
</objective>

```typescript
export interface AppBundleManifestEntry {
	field: string;
	relativePath: string;
}

export class AppBundleUploadError extends Error {
	statusCode: 400;
	constructor(message: string);
}

export function assertSafeAppBundleName(bundleName: string): string;
export function parseAppBundleManifest(raw: string): AppBundleManifestEntry[];
export function validateAppBundleManifest(entries: AppBundleManifestEntry[]): void;
export function resolveBundleFilePath(bundleRoot: string, relativePath: string): string;
```

Implementation requirements:
- `AppBundleUploadError` sets `this.name = "AppBundleUploadError"` and `this.statusCode = 400`.
- All helper validation failures throw `new AppBundleUploadError(message)`, not generic `Error`.
- `assertSafeAppBundleName` returns the original `bundleName` only when all are true:
  - value is non-empty
  - value ends with `.app`
  - `basename(bundleName) === bundleName`
  - value does not contain `/`, `\\`, or `\0`
- `parseAppBundleManifest` parses JSON and requires an array of objects where `field` and `relativePath` are strings.
- `validateAppBundleManifest` requires:
  - at least one entry
  - every `field` matches `/^bundle-file-\d+$/`
  - fields are unique
  - relative paths are unique
  - at least one entry has `relativePath === "Info.plist"`
- `resolveBundleFilePath` rejects any `relativePath` that is empty, absolute, contains `\0`, contains backslash, normalizes to `.`, starts with `..`, or contains a `..` path segment. It returns an absolute destination path only if `resolve(bundleRoot, normalizedRelativePath)` is inside `resolve(bundleRoot)`.

- parses a manifest containing `{ "field": "bundle-file-0", "relativePath": "Info.plist" }`

Update `packages/modules/app-management/routes.ts` while preserving the existing endpoint path `/install/:deviceId`.

Imports:
- Keep `createWriteStream`
- Add `mkdir`, `rename` from `node:fs/promises`
- Add `basename`, `dirname`, `join` from `node:path`
- Import `pipeline` as today
- Import `AppBundleUploadError` and helper APIs from `./upload-utils.js`

Multipart configuration:
```typescript
await fastify.register(multipart, {
	limits: { fileSize: 500_000_000, files: 5000, fields: 3, parts: 5005 },
});
```

Route behavior:
1. Keep the existing device lookup, booted-device guard, adapter lookup, and `adapter.installApp` guard before reading the upload stream.
2. Replace `await req.file()` with `for await (const part of req.parts())`.
3. Create one temp dir: `const tmpDir = await mkdtemp(join(tmpdir(), "simvyn-upload-"));`
4. For field parts, accept only:
   - `uploadType`
   - `bundleName`
   - `manifest`
   Store their string values.
5. For file parts:
   - If `part.fieldname === "file"`, write it to `join(tmpDir, basename(part.filename))` and remember `singleFilePath`.
   - If `part.fieldname` matches `/^bundle-file-\d+$/`, write it to `join(tmpDir, "parts", part.fieldname)` and remember the staging path in `Map<string, string>`.
   - Any other file field throws `new AppBundleUploadError("Unexpected upload field: " + part.fieldname)`.
6. If `uploadType !== "app-bundle"`:
   - Require `singleFilePath`, otherwise throw `new AppBundleUploadError("No file uploaded")`.
   - Call `await adapter.installApp(device.id, singleFilePath)`.
   - Return `{ success: true }`.
7. If `uploadType === "app-bundle"`:
   - If `device.platform !== "ios"` or `device.id.startsWith("physical:")`, throw `new AppBundleUploadError(".app bundles can only be installed on iOS simulators")`.
   - Validate `bundleName` with `assertSafeAppBundleName`.
   - Parse `manifest` with `parseAppBundleManifest`.
   - Validate entries with `validateAppBundleManifest`.
   - Ensure every manifest `field` exists in the uploaded file map; missing fields throw `new AppBundleUploadError("Missing uploaded file for " + field)`.
   - Create `bundleRoot = join(tmpDir, safeBundleName)`.
   - For each manifest entry:
     - `destination = resolveBundleFilePath(bundleRoot, entry.relativePath)`
     - `await mkdir(dirname(destination), { recursive: true })`
     - `await rename(stagedPath, destination)`
   - Call `await adapter.installApp(device.id, bundleRoot)`.
   - Return `{ success: true }`.
8. Keep temp cleanup in `finally`: `await rm(tmpDir, { recursive: true, force: true }).catch(() => {});`

Error handling:
- In the catch block, if `err instanceof AppBundleUploadError`, return `reply.status(400).send({ error: err.message })`.
- Adapter/install failures should keep returning HTTP 500 with `(err as Error).message`.
- Do not rely on client-side validation for any server decision.
