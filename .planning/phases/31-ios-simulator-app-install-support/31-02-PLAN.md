```typescript
const PACKAGE_ERROR = "Only .ipa, .apk, and iOS simulator .app bundles are accepted";
```

```typescript
const bundleInputRef = useRef<HTMLInputElement>(null);
```

Add a `useEffect` that sets directory selection imperatively:
```typescript
useEffect(() => {
	if (bundleInputRef.current) {
		bundleInputRef.current.webkitdirectory = true;
		bundleInputRef.current.multiple = true;
	}
}, []);
```

Use a typed bundle file shape:
```typescript
interface BundleUploadFile {
	file: File;
	relativePath: string;
}
```

Add `uploadAppBundle(bundleName: string, files: BundleUploadFile[])`:
- If `devicePlatform !== "ios" || isPhysicalIos`, set status to `Error: .app bundles can only be installed on iOS simulators` and return.
- If `!bundleName.endsWith(".app")`, set status to `Error: Select a directory whose name ends with .app` and return.
- If no file has `relativePath === "Info.plist"`, set status to `Error: This .app bundle is missing Info.plist` and return.
- Build `FormData`:
  - `uploadType` = `app-bundle`
  - `bundleName` = bundleName
  - `manifest` = JSON string of `{ field: "bundle-file-N", relativePath }[]`
  - append each file under its `bundle-file-N` field name
- POST to `/api/modules/apps/install/${deviceId}`.
- Reuse existing status behavior with exact copy:
  - `Installing ${bundleName}...`
  - `Installed ${bundleName}`
  - `Error: ${data.error || "Install failed"}`

Add directory input handling:
- `handleBundleInput(e)` reads `Array.from(e.target.files ?? [])`.
- Use `file.webkitRelativePath` to derive the root directory:
  - `const [rootName, ...rest] = file.webkitRelativePath.split("/")`
  - All files must share one `rootName`.
  - `relativePath` is `rest.join("/")`.
- Call `uploadAppBundle(rootName, bundleFiles)`.
- Reset `e.target.value = ""`.

Add drag/drop directory handling:
- Inspect `Array.from(e.dataTransfer.items)`.
- For each item, call `item.webkitGetAsEntry()`.
- If exactly one dropped entry is a directory whose name ends with `.app`, recursively collect files using `FileSystemDirectoryEntry.createReader().readEntries()` and `FileSystemFileEntry.file()`.
- Build relative paths without the root directory name.
- Call `uploadAppBundle(entry.name, collectedFiles)`.
- Otherwise, fall back to the existing single-file handling for the first `.ipa`/`.apk` file.
- If neither valid case exists, set `PACKAGE_ERROR`.

Update single-file validation:
- Accept only `ipa` and `apk`.
- Unsupported files set status to `Error: Only .ipa, .apk, and iOS simulator .app bundles are accepted`.

Update rendered copy and controls:
- Drop instruction text must be exactly `Drop IPA, APK, or iOS .app bundle here to install`.
- Primary button label must be exactly `Browse IPA/APK File` and keep `.glass-button-primary`.
- Secondary button label must be exactly `Browse .app Bundle` and use `.glass-button`.
- Keep the existing spinner style and status line.
- Add a hidden directory input controlled by `bundleInputRef`.
